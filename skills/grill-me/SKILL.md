# Grill me

Use a decision tree, not a generic survey. Identify which facts can be checked independently and which choices belong to the user. Research the former with available tools. Do not ask the user to supply facts an agent can retrieve.

Ask exactly one important question per round, unless the user explicitly requests multiple questions. State your recommended answer with reasons and trade-offs. Make the question answerable without requiring the user to invent market evidence. Do not presume user expertise or customer needs.

After each answer: record the decision, identify the next unresolved prerequisite, and ask the next question. Carry forward previously settled constraints, budgets, gates and goals. Challenge unsupported assumptions. If evidence is weak, say so and propose a concrete validation method.

Finish when material decisions are resolved. Summarize decisions, remaining unknowns and verifiable next steps. Do not begin implementation until the user authorizes it when the session is about pre-implementation discovery.

## Source and adaptation

Adapted from Matt Pocock's `grilling` workflow at https://github.com/mattpocock/skills/blob/main/skills/productivity/grilling/SKILL.md. Unlike upstream, this variant deliberately asks one question per round to match the owner's conversation preference. No Cursor or Claude Skill tool is required.
